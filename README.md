# GATE EC 2028 Tracker

A single-page study tracker for GATE Electronics & Communication preparation.

## Features
- **Today**: study timer that logs sessions, daily plan checklist, revisions and mistakes due
- **To-do**: task list with XP, levels (Aspirant → AIR 1), streaks, confetti, and a completion heatmap
- **Overview**: syllabus coverage weighted by marks, pace planner, weekly hours chart, biggest gaps
- **Syllabus**: every EC topic with stages, weak-topic flag, PYQ tick and spaced revision (7 / 21 / 42 days)
- **Study log**: sessions, accuracy, hours by subject and a study-calendar heatmap
- **Mock tests**: score trend, accuracy, marks lost to silly errors
- **Mistake log**: redo-after-7-days workflow
- **Backup**: copy / restore all data as text

## Running it
Open `index.html` in a browser, or enable GitHub Pages for this repo.
Data is saved in your browser's local storage, so use the same browser (or move data with Copy backup / Restore).
